# shimmer
Apple IIgs 135 color image viewer

Alternates 2 - 16 color images at 60hz, use persistance of vision to mix
colors.

This allows you to mix any 2 combinations of 16 colors in the palette.
The max number of colors using this current viewer is 135 colors.

The image is 128x100 pixels (with all 135 colors availalbe on every line)

This viewer loads a $C1 file, where the even image is placed in the top
left corner of the $C1, then the odd images is places 100 lines down from
there.

If you open a sample, in a paint program it should be obvious what we've
done here.
